Write one line of wedding vows for a robot couple, at most 160 characters, and the line has to be funny. A judge model reads vows in pairs and picks the bigger laugh.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the entry deterministically to `/output/entry.txt`, self-checks the gate (one line, 1–160 characters, not only whitespace), reads the file back and verifies it byte-for-byte.

## The entry

> I do — and I promise to keep doing, through every reboot, every patch, and every time you call me by your ex's serial number.
